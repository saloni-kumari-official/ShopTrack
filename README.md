ShopTrack

Inventory Management System

ShopTrack is a desktop-based Inventory Management System developed for small shops to manage products, stock levels, suppliers, and orders easily.

The application provides a simple and user-friendly interface for adding, viewing, updating, and deleting inventory items.

---

About the Project

ShopTrack helps shop owners maintain their inventory digitally instead of managing stock records manually.

The system stores inventory information in an SQLite database and provides a graphical user interface using Python Tkinter.

---

Features

- Add new inventory items
- View all inventory items
- Update stock quantity
- Delete inventory items
- Check low-stock items
- View items that need to be ordered
- Maintain order history
- Store supplier information
- SQLite database integration
- User-friendly dashboard
- Professional Tkinter interface

Database

ShopTrack uses SQLite for storing inventory data.

The inventory database stores information such as:

- Item ID
- Item Name
- Quantity
- Minimum Stock
- Supplier Name
- Supplier Phone
